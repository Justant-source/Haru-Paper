# 07 — 위젯 그리드 작업지시서 (포맷 스키마 v3)

> 2026-09-18 결정. 드래그 편집기(v2 행/슬롯, `.temp/04`)를 **폐기**하고, 안드로이드 홈 화면 위젯처럼
> "미리 정해진 몇×몇 크기의 위젯을 4열 그리드에 놓는" 방식으로 바꾼다. 자유도를 먼저 주지 않고,

## 2. 그리드 규격 [기본값] — `GridSpec.java`가 원본

```
용지 110mm − 좌우 여백 3mm×2 = 콘텐츠 폭 104mm (300dpi·1300px 프로필에서 1230px)
4열, 칸 간격 2mm   → 1열 24.5 / 2열 51 / 3열 77.5 / 4열 104 mm
행 단위 12mm, 간격 2mm → r행 = 12r + 2(r−1) → 1행 12 / 2행 26 / 4행 54 / 6행 82 mm
```

| 크기 id | 실제 크기 | 비율 | 쓰임 |
|---|---|---|---|
| `4x1` | 104×12mm | 띠 | 날짜 머리글 |
| `4x2` | 104×26mm | 4:1 | 날씨 한 줄 요약 |
| `2x4` | 51×54mm | ≈1:1 | 날씨·증시 절반 폭(둘을 나란히) |
| `4x4` | 104×54mm | ≈2:1 | 날씨 시간대별 / 증시 넓은 차트 |
| `4x6` | 104×82mm | ≈5:4 | 증시 큰 차트 |
| `4xauto` | 104×내용 길이 | — | 아침편지·메모처럼 길이가 그날그날 다른 글. **자동 높이는 항상 4열**(고정 높이 위젯과 한 줄에 섞이면 빈 공간이 생겨서 막았다) |

고정 크기 위젯은 내용이 넘치면 잘린다(`contain: size; overflow: hidden`). 옆 위젯 때문에 박스가 더 커질 수는 있으므로 위젯 루트는 `width:100%; height:100%`.

## 3. 포맷 스키마 v3

```json
{
  "schemaVersion": 3,
  "meta": { "name": "아침 브리핑", "author": "", "description": "", "forkedFrom": null },
  "style": { "fontFamily": "Pretendard", "baseFontSizePt": 11, "lineHeight": 1.4,
             "marginMm": { "top": 3, "right": 3, "bottom": 8, "left": 3 }, "blockGapMm": 3, "divider": "none" },
  "widgets": [
    { "id": "uuid-1", "type": "dateHeader",    "size": "4x1",    "props": { "pattern": "YYYY년 M월 D일 dddd" } },
    { "id": "uuid-2", "type": "morningLetter", "size": "4xauto", "props": { "showComment": true, "fontSize": "normal" } },
    { "id": "uuid-3", "type": "weather",       "size": "2x4",    "props": { "location": { "label": "경기도 성남시 분당구", "lat": 37.3827, "lon": 127.1189 } } },
    { "id": "uuid-4", "type": "stockChart",    "size": "2x4",    "props": { "ticker": "AAPL", "days": 14 } }
  ]
}
```

### 3.1 루트

| 필드 | 제약 |
|---|---|
| `schemaVersion` | 쓰기(생성·수정·미리보기)는 **3만** 허용. 가져오기(import)는 1·2·3 허용(1·2는 검증 전에 v3로 변환). 4 이상 → 422 |
| `meta` | v2와 동일(name 1~100, author 0~100, description 0~500, forkedFrom은 서버만 채움) |
| `style` | `FormatStyle` record 그대로(필드·범위 동일). v3 그리드는 `fontFamily`·`baseFontSizePt`·`lineHeight`·`marginMm`만 쓴다. `blockGapMm`·`divider`는 **받되 무시**(그리드 간격은 `GridSpec.GAP_MM` 고정, 구분선은 각 위젯이 스스로 그린다) |
| `widgets` | **1~20개**(`GridSpec.MAX_WIDGETS`). 그 밖의 루트 키(`rows`, `blocks` 포함)는 422. `assets`는 import에서만 |

### 3.2 `widgets[i]`

| 필드 | 제약 |
|---|---|
| `id` | 문자열 1~64자, 문서 안에서 유일 |
| `type` | `WidgetRegistry`에 등록된 type. 모르는 값 → 422 (`catalog=false` 위젯도 허용 — 호환용) |
| `size` | 그 위젯 `descriptor.sizes[].id` 중 하나 |
| `props` | 객체(필수, 빈 객체 가능). 키는 `descriptor.fields[].key`뿐 — 모르는 키 → 422. 값은 kind별 규칙(`PropField` javadoc) + `required`. 통과하면 `Widget.validateProps()` 추가 검증 |
| 그 밖의 키 | 422 |

kind별 검증(`WidgetPropsValidator`, S1 담당):
`string`/`text` → String, `maxLength`, `pattern`(전체 일치, string만) · `integer` → 정수(Number이고 소수부 없음), `min`~`max` · `boolean` → Boolean ·
`enum` → `options[].value` 중 하나 · `koreaLocation` → `{label: 1~50자, lat: 33.0~39.0, lon: 124.0~132.0}` 그 밖의 키 거부 · `asset` → String, `AssetRepository.existsById`.
`required=true`인데 값이 없거나(null) 빈 문자열이면 오류. 오류 경로는 `widgets[2].props.ticker` 형식.

### 3.3 Up-convert (읽기 전용 경로 + import)

| 원본 | v3 결과 |
|---|---|
| v1 `blocks[]` / v2 `rows[].slots[].block` | 문서 순서대로 펼쳐 위젯 1개씩(2슬롯 행도 그냥 차례로). `id`는 새 uuid(v2면 slot id 재사용) |
| `text` | `{type:"text", size:"4xauto", props:{text, align?, fontSizePt?, bold?}}` — 블록 style의 `align`·`fontSizePt`(정수로 반올림)·`bold`를 props로 옮긴다. `marginTopMm`/`marginBottomMm`는 버린다 |
| `dateHeader` | `{type:"dateHeader", size:"4x1", props:{pattern?, align?, fontSizePt?, bold?}}` |
| `image` | `{type:"image", size:"4xauto", props:{assetId, widthPercent?, align?}}` |
| `weather` | `{type:"weather", size:"4x2", props:{location:{label:"서울",lat:37.5665,lon:126.9780}}}` — 옛 블록은 위치가 없었다(항상 서울시청으로 렌더되고 있었음). `fields`는 버린다 |
| 빈 결과(블록 0개) | `text` 위젯 1개(`text:""`)를 넣어 "1개 이상" 규칙을 지킨다 |

DB 일괄 마이그레이션은 하지 않는다[기본값] — 읽을 때 변환, 다시 저장되면 v3로 직렬화.
**`RenderServiceImpl.doRender`가 `objectMapper.readValue(body, FormatDocument.class)`로 직접 읽고 있다 → 반드시 `FormatDocumentSupport.readDocument()`로 바꾼다**(안 그러면 v1·v2 저장본의 예약 렌더가 전부 실패한다).

## 4. 위젯 프레임워크 (Fable이 작성한 계약 — 고치지 말 것)

`server/src/main/java/com/harupaper/server/widget/`:
`GridSpec` · `WidgetSize` · `PropField` · `WidgetDescriptor` · `WidgetInstance` · `WidgetRenderContext` · `Widget` · `WidgetHtml` · `WidgetRegistry` · `WidgetPageBuilder`
테스트 도구: `src/test/.../widget/WidgetPreviewHarness`(위젯을 실제 골격 그대로 PNG로 떠서 눈으로 확인 — `build/widget-previews/*.png`).

계약을 바꿔야만 한다고 판단되면 **고치지 말고** 최종 보고에 "계약 변경 요청"으로 적는다(다른 에이전트가 같은 계약에 맞춰 동시에 작업 중이다).

`Widget` 구현 규칙은 `Widget.java` javadoc이 원본이다. 요약: ① 외부에서 온 문자열은 전부 `WidgetHtml.escape` ② 조회 실패해도 예외 금지 → 직전 캐시 또는 `WidgetHtml.errorBox` ③ 흑/백만, 선 ≥3px, 글자 ≥7pt ④ 고정 크기는 박스 안에, 루트는 100%×100% ⑤ 외부 URL은 고정 호스트만.

### 데이터 제공자 공통 규칙 [기본값]
- HTTP: Spring `RestClient` + `SimpleClientHttpRequestFactory`, 연결·읽기 타임아웃 각 5초, 재시도 1회(기존 `OpenMeteoWeatherProvider` 패턴).
- 메모리 캐시 TTL **30분**(증시는 15분), 실패 시 **24시간**(아침편지·증시는 72시간 — 주말·일요일 휴간) 안의 직전 값을 "stale"로 돌려준다. 서버 재기동 시 캐시가 비는 것은 PoC에서 수용.
- `User-Agent`는 일반 브라우저 문자열. 같은 자원을 30분 안에 두 번 치지 않는다(상대 서버 예의).
- 제공자는 인터페이스 뒤에 둔다(테스트에서 가짜로 교체). 단위 테스트는 **네트워크를 타지 않는다** — 저장해 둔 고정 응답(fixture)만 쓴다. fixture에 실제 저작물 본문을 넣지 않는다(공개 저장소) — 같은 HTML 구조의 지어낸 문장을 쓴다.

## 5. 위젯 명세

### 5.1 `morningLetter` — 고도원의 아침편지 (담당 S2, 패키지 `widget/letter/`)

- 출처: `https://www.godowon.com/` (UTF-8 [확인됨]). 파서: jsoup(`build.gradle`에 추가돼 있음).
- HTML 구조 [확인됨·실측 2026-09-18]:
  ```html
  <div class="todayLetter"> … <span class="letterDate">2026년 9월 18일 오늘의 아침편지</span> …
    <div class="mainletterContents">
      <h3 class="mainLetterTit">제목</h3>
      <p> 본문 줄1<br /> 본문 줄2<br /> … <br /><br /> - 아무개의《책 이름》중에서 -<br /><br /><br /> * 고도원의 한마디 줄1<br /> … <br /><br /> 오늘도 많이 웃으세요. </p>
  ```
- 파싱: `<br>` → 줄바꿈, 줄별 trim. `^-\s.+\s-$` 에 맞는 **첫 줄**이 출처(source). 그 앞 = 인용문(quote), 그 뒤 = 한마디(comment). 출처 줄이 없으면 전부 quote. 연속된 빈 줄은 1개로 줄이고 앞뒤 빈 줄 제거. comment 첫 줄의 `* ` 접두사는 제거.
  결과 record: `MorningLetter(dateText, title, quote, source, comment, fetchedAt, stale)`.
- 크기: `4xauto`(previewRows 8) 하나.
- props: `showComment` boolean 기본 true("고도원의 한마디 포함") · `fontSize` enum `small|normal|large` 기본 `normal`(본문 10 / 11 / 12.5pt).
- 레이아웃 — **선으로 틀을 잡아 글에 집중하게** (사용자 요구):
  ```
  ━━━━━━━━━━━━━━━━━━━━━━━━━━  굵은 선(≈0.6mm)
   고도원의 아침편지 · 2026년 9월 18일      작은 글자(8.5pt), 가운데, 자간 넓게
  ──────────────────────────  가는 선(≈0.25mm)
          제목 (굵게 14pt, 가운데)
  
   인용문 본문 — 원문 줄바꿈 유지(white-space: pre-line), 왼쪽 정렬, 좌우 안쪽 여백 3mm,
   줄이 폭을 넘으면 자연 줄바꿈
  
                  - 아무개의《책 이름》중에서 -   (오른쪽 정렬 9.5pt)
  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  점선
   한마디 (showComment일 때만, 10pt)
  ━━━━━━━━━━━━━━━━━━━━━━━━━━  굵은 선
  ```
- 실패 표시: `WidgetHtml.errorBox("고도원의 아침편지", "편지를 가져오지 못했습니다", ctx)`. 구조가 바뀌어 제목·본문을 못 찾은 것도 실패로 본다(로그 WARN).

### 5.2 `stockChart` — 미국 증시 일봉 (담당 S3, 패키지 `widget/stock/`)

- 출처: `https://query1.finance.yahoo.com/v8/finance/chart/{TICKER}?range=6mo&interval=1d` (실패 시 `query2` 1회). 응답: `chart.result[0].timestamp[]`, `.indicators.quote[0].{open,high,low,close}[]`(null 섞임 — 넷 중 하나라도 null인 봉은 버린다), `.meta.{symbol,shortName,currency,regularMarketPrice,exchangeTimezoneName}`. 없는 티커는 `chart.error` 또는 404.
- 인터페이스: `StockQuoteProvider { StockSeries getDaily(String symbol, int days) }` — 나중에 환율(`KRW=X`) 등으로 넓힐 수 있게 이름을 symbol로 둔다. **지금은 미국 증시 티커만**.
- props: `ticker` string 필수, 정규식 `^[A-Z]{1,5}([.-][A-Z]{1,2})?$`(예: AAPL, BRK-B, BRK.B), placeholder "AAPL" · `days` integer 기본 **14**, 5~60("최근 N거래일").
  **대문자만 허용**한다(소문자는 422 — 앱이 입력을 대문자로 바꿔 보낸다). Yahoo 호출 때 `.`은 `-`로 바꾼다(BRK.B → BRK-B).
- 크기: `2x4`(기본) · `4x4` · `4x6`.
- 그리기(인라인 SVG, viewBox = 박스 px):
  - 머리: **티커(굵게)** + 회사명(넓은 크기만, 말줄임) / 마지막 종가 `332.32`(크게, 굵게) + 통화 / 전 거래일 대비 `▲ 1.23 (+0.37%)` — 오름 ▲, 내림 ▼, 보합 −. (글리프 대신 SVG 삼각형을 써도 된다.) / 마지막 봉 날짜 `9/17 종가`(거래소 현지 날짜).
  - 차트: 캔들스틱. **오른 날 = 속 빈 상자(흰 채움+검은 테두리), 내린 날 = 검게 채움**, 심지 선. 가로 점선 눈금 2~3개 + 오른쪽에 가격 라벨(최고/최저 포함), 아래에 첫날·마지막 날 `M/D`. 봉 폭은 칸 폭의 60~70%.
  - N개 미만이면 있는 만큼만. 0개면 실패 표시.
- 실패 표시: `errorBox(ticker, "시세를 가져오지 못했습니다")`, 없는 티커면 `"티커를 찾을 수 없습니다"`.
- 알려진 한계[기본값]: 렌더 시각에 장이 열려 있으면 마지막 봉은 진행 중인 봉이다. 겨울(EST)엔 장 마감이 KST 06:00이라 06:00 재렌더와 겹칠 수 있다 — 문서에 적고 수용.

### 5.3 `weather` — 오늘의 날씨 (담당 S4, 패키지 `widget/weather/` + `weather/`)

- 출처: Open-Meteo forecast. 기존 호출에 `hourly=temperature_2m,precipitation_probability,weather_code`를 더해 **시간대별**도 받는다. 새 API: `ForecastProvider { DayForecast getForecast(double lat, double lon, LocalDate date) }`,
  `DayForecast(date, tempMin, tempMax, precipProb, weatherCode, skyText, List<HourPoint> hours, fetchedAt, stale)`, `HourPoint(hour, temp, precipProb, weatherCode)`.
  기존 `WeatherProvider.getDaily()`·`DailyWeather`·`OpenMeteoWeatherProvider.clearCache()`의 **공개 시그니처는 유지**한다(`SettingsController`·기존 테스트가 쓴다). `weather/` 패키지 내부 리팩터링은 S4 재량.
- props: `location` koreaLocation **필수**(기본값 없음 — 사용자가 직접 고른다).
- 크기: `2x4`(기본) · `4x2` · `4x4`.
  - `2x4`: 위치 이름 / 큰 날씨 아이콘 / 하늘 상태 / `최고 27° · 최저 18°` / `강수확률 30%`.
  - `4x2`: 가로 한 줄 — 아이콘 | 위치+하늘 상태 | 최고/최저 | 강수확률.
  - `4x4`: 왼쪽 1/3은 `2x4` 요약, 오른쪽 2/3는 **06·09·12·15·18·21시** 6칸(작은 아이콘, 기온, 강수확률).
- 아이콘: WMO 코드 → 8종(맑음, 구름 조금, 흐림, 안개, 비, 눈, 소나기, 뇌우) 흑백 선 SVG. 선 굵기는 뷰박스 기준으로 박스에서 3px 이상이 되게.
- 위치 목록: `server/src/main/resources/widgets/korea-locations.json` — 시·도 17개 + 시·군·구 전부(약 250개, 일반구 포함: 성남시 분당구 등). 항목 `{sido, name, lat, lon}`.
  좌표는 **기억으로 쓰지 말고** `server/scripts/build-korea-locations.py`로 만든다: 이름 목록(스크립트 안에 고정) → Nominatim(`https://nominatim.openstreetmap.org/search`, `countrycodes=kr`, **1초에 1건 이하**, 식별 가능한 User-Agent) → 대한민국 범위(33~39N, 124~132E) 검증 → JSON. 실패 항목은 로그로 남기고 수동 보완. 결과 파일과 스크립트를 둘 다 커밋한다. 출처 표기: "© OpenStreetMap contributors (ODbL)"를 JSON 옆 `README` 또는 스크립트 머리말에.
- API: `GET /api/widgets/locations` → `[{sido, name, label, lat, lon}]` (`label = sido + " " + name`, 시·도 자체 항목은 `label = sido`). 인증 필요(기본 `/api/**` 규칙). 컨트롤러는 `widget/weather/KoreaLocationController`.
- 실패 표시: `errorBox(location.label, "날씨 정보를 가져오지 못했습니다")`.

## 7. 앱 (React)

계약(Fable 작성, 고치지 말 것): `src/types/format.ts`(v3) · `src/types/widget.ts` · `src/api/widgets.ts` · `src/lib/format-templates.ts`.

### 7.1 포맷 편집 화면 (담당 A1)
한 손 폰 사용 기준. 위에서 아래로:
1. 헤더: 뒤로 · 저장 상태 · **저장** 버튼.
2. 포맷 이름 입력(설명은 접힌 상태).
3. **배치도**: 서버와 같은 4열 CSS 그리드(`grid-auto-flow: row dense`, 열 4, 행 높이 = 열폭×(12/24.5), 간격 비례)로 위젯을 상자로 그린다. 상자 안: 아이콘·이름·요약(예: `AAPL · 14일`, `성남시 분당구`). 자동 높이 위젯은 `previewRows`행으로 그리고 아래쪽을 물결/점선으로 표시("내용 길이만큼"). 상자를 누르면 그 위젯 설정 시트.
4. **위젯 목록**(순서 = 인쇄 순서): 카드마다 ▲▼(순서 이동) · 설정 · 삭제. 드래그 없음.
5. **＋ 위젯 추가** → 바텀시트 카탈로그(`catalog=true`만): 아이콘·이름·설명·크기 칩. 누르면 기본 크기·기본 props로 추가하고, 필수값이 비어 있으면(`missingRequiredFields`) 바로 설정 시트를 연다.
6. **설정 시트**: 크기 선택(세그먼트/카드, `label` 표시) + `descriptor.fields`로 **자동 생성한 폼**:
   string → input(패턴이 대문자 전용이면 입력을 대문자로), text → textarea, integer → number(±버튼), boolean → Toggle, enum → select/세그먼트,
   koreaLocation → **검색 가능한 시·군·구 선택기**(`widgetsApi.locations()`를 받아 앱에서 부분 일치 검색, 시·도별 묶음, 선택 시 `{label,lat,lon}` 저장) , asset → "이 앱 버전에서는 편집할 수 없습니다" 안내.
   `catalog=false`이거나 카탈로그에 없는 type의 위젯은 "이전 버전 위젯" 카드로 보여 주고 삭제·순서 이동만 허용.
7. **미리보기**: 서버 실제 렌더(`formatsApi.previewEphemeralBlob`) — 1초 디바운스, 위젯이 0개거나 필수값이 비어 있으면 호출하지 않고 안내문. 화면에 항상 보이는 섹션(접기 가능)으로 둔다. 422면 필드 오류를 해당 위젯 카드에 표시.
8. 저장 후 **"이 포맷으로 예약하기"** 버튼 → `/schedules?formatId=<id>` , **"지금 인쇄"** → `/print-now?formatId=<id>`.
- 저장 안 한 변경이 있으면 나갈 때 확인(기존 동작 유지). 서버 422의 `errors[].path`(`widgets[2].props.ticker`)를 해당 위젯에 매핑.
- CSS는 `src/index.css`에서 옛 편집기 규칙(`.layout-*`, `.widget-palette*` 등 안 쓰는 것)을 지우고 새 규칙을 넣는다. 다크/라이트 테마 변수(`lib/theme.ts`, 기존 CSS 변수)를 따른다. `@dnd-kit/*` 의존성 제거(`npm uninstall`).

### 7.2 포맷 목록·예약 흐름 (담당 A2)
- `FormatListPage`: **새 포맷** → 시트에서 고른다: ① **아침 브리핑**(추천) = `dateHeader 4x1` + `morningLetter 4xauto` + `weather 2x4` + `stockChart 2x4`(ticker 기본 `AAPL`; 날씨 위치는 비워 둠 → 편집 화면이 바로 설정을 요구) ② **빈 포맷**. 카탈로그(`widgetsApi.catalog()`)와 `newWidgetInstance()`로 만든다. 서버는 위젯 1개 이상을 요구하므로 "빈 포맷"은 **저장하지 않고** `/formats/new`로 이동(편집 화면이 첫 저장을 한다), "아침 브리핑"도 날씨 위치가 필수라 저장 없이 `/formats/new?template=morning`으로 이동 — 템플릿 조립 함수 `buildTemplate(name, catalog)`는 계약 파일 `src/lib/format-templates.ts`에 이미 있다(Fable 작성). A1의 편집 화면이 `template` 쿼리를 읽어 그 함수를 부른다. A2는 이동만 시킨다.
  카드: 썸네일(기존) · 이름 · 수정 시각 · "동적" 배지(`hasDynamicBlocks`) · 메뉴(편집/예약하기/지금 인쇄/내보내기/삭제).
- `ScheduleListPage`: `?formatId=`로 들어오면 새 예약 시트를 그 포맷이 선택된 채로 연다(쿼리는 열고 나서 지운다). 새 예약의 요일 기본값 = **매일(7일 전부)**, 시각 기본 07:00. "매일/평일/주말" 빠른 선택 칩. 예약 카드에 포맷 썸네일.
- `SettingsPage`: "날씨 기본 위치" 섹션 제거(위치는 이제 날씨 위젯 설정에 있다). 서버 `/api/settings`는 그대로 둔다. `api/settings.ts`·`types/settings.ts`가 더는 안 쓰이면 삭제.
- `PrintNowPage`: `?formatId=` 동작 확인만(이미 구현돼 있음). 고칠 게 없으면 손대지 않는다.
- A2는 `src/index.css`·`src/i18n/*`를 **건드리지 않는다**(A1 소유). 새 스타일은 `src/styles/format-flow.css`에 두고 자기 페이지에서 import. 새 문구는 한국어 리터럴.

## 9. 공통 규칙 (CLAUDE.md 발췌)

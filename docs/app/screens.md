# 화면 명세 (웹앱 MVP 7개)

> 담당: 서버 세션 / 마일스톤: **M3** / 기준: [../init_plan.md](../init_plan.md) 8.3절
> API 경로는 [../architecture.md](../architecture.md) 규약 이름 그대로. 포맷 구조는 [../server/format-schema.md](../server/format-schema.md)
> 표기: **[기본값]** = 따로 묻지 않고 정한 값(M3에서 바꿔도 됨)

## 공통

- **모바일 우선**: 기준 폭 360~412px(Android `s21`). 데스크톱은 가운데 정렬된 좁은 컬럼으로 충분.
- **크롬** [기본값]: 셸 최대폭 480px, 바깥 배경 `--bg-page`(`#f4ede3`) 우드톤, 카드 `--bg-surface`. 탭 루트는 sticky `PageHeader`. 하단 탭 4개(`포맷` · `예약` · `지금 인쇄` · `더보기`)는 SVG 라인 아이콘+라벨. 포맷 편집은 하위 화면이라 하단 탭을 숨긴다. 목록 메뉴·삭제 확인은 하단 시트. PWA `theme_color`/`background_color`는 `#f4ede3`. 설정에서 어두운 테마·영어 UI(크롬 문구)를 고를 수 있다.
- **내비게이션** [기본값]: 하단 탭 4개 — `포맷` · `예약` · `지금 인쇄` · `더보기`(이력 / 기기 / 설정). 포맷 편집은 포맷 목록에서 들어가는 하위 화면.
- **시각 표시**: 전부 KST. 날짜 `2026-09-14 (월)`, 시각 `07:00` 형식 [기본값].
- **연결 오류 공통 처리**: `/api` 요청이 네트워크 오류로 실패하면 상단 배너 "서버에 연결할 수 없습니다. 폰의 Tailscale이 켜져 있는지 확인하세요." + 다시 시도 버튼.
- **서버 오류 응답**: 서버는 `application/problem+json`(`{type, title, status, detail, instance, errors[]}`, [../architecture.md](../architecture.md) 4.1)으로 답한다. 검증 오류(422, 일부 400)는 `errors[].path`(예: `blocks[2].props.text`)로 해당 입력을 찾아 `errors[].message`를 옆에 표시. 그 밖의 오류는 `detail`(없으면 `title`)을 토스트로.
- **삭제 확인**: 포맷·예약 삭제는 하단 시트로 확인한다.

## (1) 포맷 목록

**목적**: 내 포맷(=카드) 라이브러리. 새로 만들기, 가져오기, 내보내기의 출발점.

**표시 요소**
- 포맷 카드 목록: 이름(`meta.name`), 설명, 가져온 포맷이면 "원작자: {forkedFrom.author}" 표시, 마지막 수정 시각
- 썸네일 [기본값]: 저장된 포맷의 `GET /api/formats/{id}/preview.png` 상단 일부. 목록 로딩이 느리면 M3에서 생략 가능
- 버튼: `새 포맷`, `가져오기`
- 각 포맷 메뉴: `편집`, `내보내기`, `지금 인쇄`(→ 화면 4에 포맷 선택된 상태로 이동), `삭제`

**사용자 동작**
| 동작 | API |
|---|---|
| 목록 로드 | `GET /api/formats` |
| 새 포맷 | `POST /api/formats` (기본 스타일 + 날짜 헤더 블록 1개 [기본값]) → 화면 2로 이동 |
| 가져오기 | 파일 선택(.json) 또는 JSON 붙여넣기 → `POST /api/formats/import` → 새로 생긴 포맷 편집 화면으로 |
| 내보내기 | `GET /api/formats/{id}/export` → JSON 파일 다운로드(파일명은 서버 `Content-Disposition`의 `<name>.haru-format.json`) |
| 삭제 | `DELETE /api/formats/{id}` |

**빈 상태**: "아직 포맷이 없습니다. 첫 카드를 만들어 보세요." + `새 포맷` 버튼
**오류 상태**
- 가져오기 실패(스키마 불일치·버전 미지원): 서버 오류 메시지를 대화상자로 표시, 포맷은 생성되지 않음
- 예약에 쓰이는 포맷 삭제 시도: 서버가 거부하면 "이 포맷을 쓰는 예약이 있습니다" 표시(삭제 규칙은 M2 서버 결정을 따름)

**레이아웃 메모**: 한 줄에 카드 1개. 메뉴는 카드 오른쪽 `⋯` 버튼 → 하단 시트.

## (2) 포맷 편집

**목적**: 드래그로 블록을 쌓아 카드를 만들고, 스타일을 조정하고, 인쇄물과 똑같은 미리보기를 본다.

**표시 요소**
- 상단: 포맷 이름 입력, 설명 입력, **`저장` 버튼(명시적 저장)**, 저장 상태(저장됨 / 변경 사항 있음)
- **레이아웃 캔버스**: 종이 비율 프레임에 행/슬롯을 그린다
  - 각 행: 슬롯 1개(폭 100%) 또는 슬롯 2개(폭 비율 조합 3가지)
  - 각 슬롯: 블록 하나(종류 아이콘 + 요약)를 표시
  - **슬롯 탭**: 드래그 아님, 탭하면 속성 편집 시트를 열어 블록을 수정
  - **행/슬롯 드래그**: 순서 재배치 가능
  - **2슬롯 행 리사이즈**: 가운데 손잡이를 좌우로 드래그해 폭 비율 조정(3개 스냅 위치로 스냅)
  - **삭제**: 슬롯을 화면 하단 휴지통 드롭존으로 끌면 삭제 + 5초 Undo
- **블록 팔레트**: 하단 또는 시트로, 블록 4종 카드를 드래그해 캔버스에 추가
  - 팔레트 → 캔버스 드래그: 새 행 추가
  - 드롭 위치: 캔버스 맨 위/맨 아래 또는 기존 행 사이
- **전체 스타일** 폼(접힘): `fontFamily`, `baseFontSizePt`, `lineHeight`, `marginMm`(상하좌우), `blockGapMm`, `divider`
- **"정확히 보기" 버튼**: 누르면 모달/시트로 서버 미리보기 PNG 표시

**블록별 편집 폼** (속성 이름은 format-schema.md 원본을 따른다)
| 블록 | 편집 항목 |
|---|---|
| `text` | 여러 줄 텍스트. **변수 삽입 버튼**: `{{date}}`, `{{weekday}}` — 커서 위치에 삽입 |
| `image` | 이미지 선택(카메라/갤러리, PNG/JPEG만) → `POST /api/assets` 업로드(최대 10MB, 초과 시 업로드 전에 안내) → `assetId` 저장, 썸네일은 `GET /api/assets/{assetId}`, `widthPercent` 슬라이더 |
| `dateHeader` | `pattern` 선택/입력(예: `YYYY년 M월 D일 dddd`) |
| `weather` | `location`(`default` = 설정 화면의 기본 위치), 표시 필드 체크박스: 최저기온 / 최고기온 / 강수확률 / 하늘 상태 |

**블록 스타일 폼**: **화이트리스트 속성만** 노출 — `align`(왼쪽/가운데/오른쪽), `fontSizePt`, `bold`, `marginTopMm`, `marginBottomMm`. 자유 CSS·HTML 입력란은 **만들지 않는다**(SSRF·JS 실행 방지, init_plan 6.1).

**사용자 동작**
| 동작 | API |
|---|---|
| 편집 화면 진입 | `GET /api/formats/{id}` |
| 프린터 정보 조회 | `GET /api/device` (폭 정보 가져오기) |
| 블록 추가(드래그) | 팔레트 → 캔버스 드래그 (로컬 상태 변경) |
| 블록 삭제·순서 변경 | 드래그 조작 (로컬 상태 변경) |
| 슬롯 속성 편집 | 슬롯 탭 → 편집 시트 열기 |
| 저장 | `저장` 버튼 → `PUT /api/formats/{id}` (rows 구조) |
| 미리보기 요청 | "정확히 보기" 버튼 → 모달에서 `POST /api/formats/preview` (1초 디바운스) |

**미리보기 갱신 방식** [기본값]: "정확히 보기" 버튼을 누르면 모달이 열리고, 그 안에서 편집 중 문서 전체를 `POST /api/formats/preview`로 보내 PNG 표시(1초 디바운스, 앞선 요청이 진행 중이면 취소). **자동 저장은 하지 않는다** — 저장은 `저장` 버튼으로만 한다.

**빈 상태**: 블록이 0개면 "블록을 추가하세요" + 팔레트에서 드래그하라는 안내
**오류 상태**
- 저장 실패(검증 오류 422): `errors[].path`로 해당 블록/필드 옆 메시지
- 미리보기 검증 오류(422): 같은 방식으로 필드 옆 메시지, 미리보기는 마지막 성공본 유지 + "미리보기가 최신이 아닙니다" 표시
- 미리보기 렌더 실패: 미리보기 자리에 오류 메시지 + 다시 시도
- 이미지 10MB 초과: 업로드하지 않고 안내
- 편집 중 이탈: 저장 안 된 변경이 있으면 확인 대화상자

**레이아웃 메모**: 캔버스는 셸 480px 안에서 동작. 종이 비율 프레임으로 표시. 팔레트는 하단 고정 또는 시트로 제공. "정확히 보기" 버튼으로 모달 열기 — 미리보기 PNG는 **폭 100%로 축소 표시**하고 탭하면 원본 크기(가로 스크롤). 폭 1300px 내외 이미지를 폰 폭에 맞춰 보여주므로 글자 크기 확인용 확대 보기가 필요하다.

## (3) 예약 목록·편집

**목적**: 반복/일회성 예약을 만들고, 켜고 끈다. 예약 1개 = 포맷 1개(Q9).

**표시 요소**
- 예약 목록: 시각(`07:00`), 요일(반복: `월 화 수 목 금`) 또는 날짜(일회성: `2026-09-15 (화)`), 포맷 이름, **켜기/끄기 스위치**
- 다음 실행 예정 시각 [기본값]: 앱이 KST 기준으로 계산해 표시(표시용일 뿐, 실제 실행 판단은 Pi)
- `새 예약` 버튼

**편집 시트**
- 종류: `반복` / `일회성`
- 반복: 요일 선택(월~일 토글, 최소 1개), 시각
- 일회성: 날짜, 시각(과거 날짜·시각은 선택 불가 [기본값])
- 포맷 선택(목록에서 1개)
- 켜짐 여부
- 시간대 선택 UI 없음(KST 고정)

**사용자 동작**
| 동작 | API |
|---|---|
| 목록 로드 | `GET /api/schedules` (+ 포맷 이름 표시용 `GET /api/formats`) |
| 새 예약 | `POST /api/schedules` |
| 편집 저장 / 켜기·끄기 스위치 | `PUT /api/schedules/{id}` |
| 삭제 | `DELETE /api/schedules/{id}` |

**빈 상태**
- 예약 0개: "예약이 없습니다. 매일 아침 받을 카드를 예약하세요." + `새 예약`
- 포맷 0개인데 새 예약: "먼저 포맷을 만드세요" + 포맷 목록으로 이동 버튼

**오류 상태**
- 요일 미선택·포맷 미선택: 저장 버튼 비활성
- 스위치 변경 실패: 스위치를 원래 상태로 되돌리고 토스트

**안내 문구**(목록 하단 작은 글씨) [기본값]
- "Pi는 약 30초마다 서버에서 예약을 받아옵니다. 변경 직후 바로 반영되지 않을 수 있습니다."
- "예약 시각에 인터넷이 끊겨도 Pi가 마지막으로 받은 카드로 인쇄합니다. 이 경우 날짜·날씨는 마지막 렌더 값일 수 있습니다."

## (4) 지금 인쇄

**목적**: 선택한 포맷을 즉시 인쇄하는 명령을 보낸다.

**표시 요소**
- 포맷 선택(목록 또는 화면 1에서 넘어온 값) + 선택한 포맷 미리보기 PNG
- 기기 상태 요약: Pi 마지막 폴링 시각, 용지 정책
- **체크박스: "프린터 앞에서 용지를 눈으로 확인함"**
- `지금 인쇄` 버튼

**용지 정책별 동작** (정책 값은 `GET /api/device` 응답, 정의는 init_plan 8.1)
| 정책 | 의미 | 화면 동작 |
|---|---|---|
| `unverified` (기본, H4 통과 전) | 프린터 용지 감지가 아직 확인되지 않음. 예약 인쇄는 `dry_run` 기록만 하고, 지금 인쇄만 사람 확인 후 전송 | **체크박스를 체크해야 버튼 활성화**. 체크 없으면 버튼 비활성 + 설명 "용지 감지가 아직 확인되지 않아, 용지를 직접 확인해야 인쇄할 수 있습니다" |
| `status_query` (H4 통과 후) | Pi가 인쇄 직전 프린터에 상태를 물어 용지 확인 | 체크박스는 표시하되 필수 아님 [기본값] |
| `manual_flag` (H4 실패 시) | 서버의 수동 "용지 장착됨" 상태가 켜져 있을 때만 무인 인쇄 | 체크박스 체크 필수 [기본값]. 수동 상태가 꺼져 있으면 "기기 화면에서 용지 장착됨을 켜세요" 안내 링크 |

**사용자 동작**
| 동작 | API |
|---|---|
| 기기 상태·정책 로드 | `GET /api/device` |
| 포맷 목록·미리보기 | `GET /api/formats`, `GET /api/formats/{id}/preview.png` |
| 인쇄 | `POST /api/print-now` `{formatId, paperConfirmed}` |

**전송 후**: "명령을 보냈습니다. Pi가 다음 폴링(최대 약 30초)에 받아 인쇄합니다." + `이력 보기` 버튼. 결과는 이력 화면(5)에서 확인.

**빈 상태**: 포맷 0개 → "먼저 포맷을 만드세요"
**오류 상태**
- Pi 마지막 폴링이 오래됨 [기본값: 2분 이상]: 경고 배너 "Pi가 최근에 접속하지 않았습니다. 명령은 10분 안에 Pi가 다시 접속하면 처리되고, 그렇지 않으면 만료되어 인쇄되지 않습니다." (전송은 허용)
- 서버는 `paperConfirmed=false`여도 거절하지 않는다(판단은 Pi 용지 정책). 그래서 체크 요구는 **앱 UI에서** 한다(위 정책별 동작 표)

## (5) 이력

**목적**: 예약 실행·지금 인쇄 결과를 확인한다. Pi가 오프라인이었다면 복구 후 한꺼번에 올라온다.

**표시 요소**
- 결과 목록(최신순): 상태 라벨(색), 포맷 이름, 예약 시각(`scheduledAt`) / 실행 시각(`executedAt`), 구분(`source`: `schedule` = 예약 / `command` = 지금 인쇄), `detail`(있으면 펼쳐 보기)
- 필터 [기본값]: 전체 / 인쇄됨 / 문제 있음(printed·dry_run 외)

**상태 라벨** (`status` 7종, init_plan 6.5)
| status | 한국어 라벨 | 의미 | 색 [기본값] |
|---|---|---|---|
| `printed` | 인쇄됨 | 프린터로 전송 완료 | 초록 |
| `dry_run` | 모의 실행 | 용지 감지 미확정(`unverified`)이라 인쇄하지 않고 기록만 | 회색 |
| `missed` | 놓침 | 유예 시간(30분) 안에 실행하지 못함 | 주황 |
| `failed` | 실패 | 실행 중 오류(detail 참고) | 빨강 |
| `skipped_no_paper` | 용지 없음 | 용지가 없거나 수동 "용지 장착됨"이 꺼져 있어 건너뜀 | 주황 |
| `skipped_clock_unsynced` | 시각 미확인 | Pi 시계가 동기화되지 않아(오프라인 재부팅) 보류 | 주황 |
| `skipped_printer_offline` | 프린터 응답 없음 | 프린터 꺼짐·연결 끊김 | 빨강 |

**사용자 동작**
| 동작 | API |
|---|---|
| 목록 로드·새로고침 | `GET /api/history` (당겨서 새로고침 [기본값]) |

**빈 상태**: "아직 실행 기록이 없습니다."
**오류 상태**: 로드 실패 시 공통 연결 오류 배너

## (6) 기기

**목적**: Pi·프린터가 살아 있는지, 어떤 용지 정책으로 동작하는지 보고, 수동 용지 상태를 조작한다.

**표시 요소**
- **Pi 마지막 폴링 시각** + 경과 시간("35초 전"). 기준 초과 시 경고 [기본값: 2분]
- **프린터 프로필**: `model`(표시용, 예 `m832`), `dpi`, `paperWidthMm`, `printableWidthPx`
- **프린터 상태**: Pi가 보고한 `printerStatus` `{state, detail}`(정의는 [../architecture.md](../architecture.md) 4.3). `detail`이 있으면 라벨 아래 작은 글씨로 표시

  | `state` | 한국어 라벨 | 색 [기본값] |
  |---|---|---|
  | `ok` | 정상 | 초록 |
  | `offline` | 프린터 연결 안 됨 | 빨강 |
  | `error` | 오류 | 빨강 |
  | `unknown` | 알 수 없음 | 회색 |

  H4(용지 감지) 통과 후 `no_paper`(용지 없음), `cover_open`(커버 열림)이 추가될 예정이다. 모르는 값은 `unknown`처럼 표시한다
- **용지 정책**: `unverified` / `status_query` / `manual_flag` + 한 줄 설명(화면 4의 표와 같은 문구)
- **수동 "용지 장착됨" 토글**

**수동 "용지 장착됨" 토글의 의미**
- `manual_flag` 정책일 때만 실제로 쓰인다: 켜져 있어야 Pi가 무인(예약) 인쇄를 한다. 롤을 갈았을 때 사용자가 켠다. 프린터가 오류를 보고하면 서버가 자동으로 끈다.
- 다른 정책에서는 토글을 비활성(회색)으로 두고 "현재 정책에서는 사용하지 않습니다" 표시 [기본값].

**사용자 동작**
| 동작 | API |
|---|---|
| 상태 로드 | `GET /api/device` (화면에 있는 동안 30초마다 재조회 [기본값]) |
| 용지 장착됨 토글 | `PUT /api/device/paper-state` `{loaded}` |

**빈 상태**: Pi가 한 번도 폴링하지 않음 → "아직 Pi가 연결되지 않았습니다." (프로필·상태 칸 비움)
**오류 상태**: 토글 실패 시 원래 상태로 되돌리고 토스트

## (7) 설정

**목적**: 날씨 블록의 기본 위치 등 앱 전역 설정.

**표시 요소**
- **날씨 기본 위치**: 위도·경도 입력(기본값 서울시청 `37.5663, 126.9779`), 위치 이름(표시용) [기본값]
- 지명 검색·지도 선택은 PoC 범위 밖 [기본값] — 필요하면 이후 추가
- 앱 정보: 버전, 서버 연결 상태(`GET /api/health`)

**사용자 동작**
| 동작 | API |
|---|---|
| 설정 로드 | `GET /api/settings` |
| 저장 | `PUT /api/settings` |
| 연결 확인 | `GET /api/health` |

**빈 상태**: 해당 없음(서버 기본값 표시)
**오류 상태**: 위도(-90~90)·경도(-180~180) 범위 밖이면 저장 버튼 비활성

**안내 문구**: "날씨는 인쇄 약 60분 전에 서버가 다시 받아 카드에 반영합니다."
